# 分组与比较：让相关工作"分得清"

## 1. 组的本质

一个组 = **在同一维度上互相竞争或互补的一组工作**。判断标准只有一条：

> 把组内任意两篇放在同一句话里比较，这句话有意义吗？

有意义就是一组；只能说"A 做了甲领域，B 做了乙领域"就不是，那是两个组。

## 2. 五种可用的比较维度

选一个作主轴，其余作辅助。**同一组内所有文献必须在同一组维度上都有值**。

| 维度 | 比较轴 | `data_setting` 该写什么 | 典型取舍句 |
|---|---|---|---|
| 问题设定 | 各自解决的是哪一个子问题、边界在哪 | 任务定义与假设 | "X 假设…，而 Y 允许多…；一旦…，X 的前提不成立" |
| 方法路线 | 用什么机制达到同一目的 | 输入表示与流程 | "X 用 A 机制，Y 用 B 机制；A 省算力但要…，B 反之" |
| 数据与评价 | 在什么数据、用什么指标、与谁比 | 数据集规模/来源/划分 | "X 在…上报告…，Y 换到…后…；两者指标不可直接相减" |
| 计算代价 | 训练/推理成本随什么增长 | 资源条件 | "X 的成本随库规模线性增长，Y 与库规模无关但…" |
| 理论保证 | 有没有界/收敛/可识别性 | 假设条件 | "X 有界但只在固定特征空间；Y 无界但在学习表示上成立" |

## 3. 组内必填五字段的写法

| 字段 | 不行的写法 | 可以核对的写法 |
|---|---|---|
| `method_route` | "用了深度学习方法" | "在固定谱嵌入上做贪心 k-centre 选择，再掩码预训练" |
| `data_setting` | "多个数据集" | "MoleculeNet ESOL/Tox21 + 自有激酶面板，各 100 条标注，5 个随机种子" |
| `evaluation` | "效果更好" | "下游回归 MAE；与最强自监督基线对比；报 5 seed 均值" |
| `conclusion` | "表现优异" | "100 标注下 MAE 从 0.667 降到 0.742 准确率水平；优势随预算增长收窄" |
| `limitation` | "还有提升空间" | "界只在固定特征空间成立，无法迁移到仍在学习的表示" |

**`limitation` 是空白账的唯一来源**，写不具体，空白就推不出来。

## 4. `comparison.tradeoff` 的三种合法句式

1. **取舍型**：`A 省 X 但付出 Y；B 反之。在 <条件> 下 A 更划算。`
2. **分工型**：`A 与 B 不是竞品：A 固定了可表示空间，B 决定从中学多少。`
3. **退化型**：`A 的保证在 <条件> 下成立；一旦 <条件> 破坏，A 退化为 B 的特例。`

不要写的三种：
- `各有优缺点。`（空）
- `A 和 B 都被广泛使用。`（不是比较）
- `A 早于 B。`（这是时间顺序，不是维度比较）

## 5. 逐篇拼接的四种可识别形状（R08 会抓后两种）

| 形状 | 例子 | 是否被抓 |
|---|---|---|
| 一段一篇，连续 ≥3 段，整段无比较词 | "A 提出…。B 提出…。C 提出…。"（三段） | **R08 `serial_summary_pattern`** |
| 一段三句，每句一篇，整段无比较词 | 同上压缩成一段 | **R08 `sentence_serial_summary`** |
| 一个句子多篇并列，无比较 | "A\[1\]、B\[2\]、C\[3\] 都研究了这个方向。" | 不抓（并列不是错误，但价值低） |
| 有比较词的逐篇 | "A 提出…，相比之下 B 用…但…" | 不抓 |

## 6. 从分组到正文的映射

`ledger_groups.json` 的一组 → 正文的一段。段内固定四步，读起来自然且必然带比较：

1. **定轴**：`这一路线的共同选择是 <维度>。`
2. **并列**：把组内每篇压成"机制 + 结论"半句，**同一句里出现两篇以上**（这一句就消灭了"逐篇摘要"）。
3. **比较**：`相比之下 / 而 / 代价是 / whereas` 指出差异在哪个轴上。
4. **收口**：`这组工作的共同局限是 <limitation 的合并>，它正是下一节空白的来源。`

第 4 步是把相关工作与空白接上的唯一机制。缺了它，两节就只是相邻的两段文字。

## 7. 常见拼错的三种格局

- **按年份分段**（2018 前 / 2018–2021 / 2022 后）：时间不是维度，是索引。除非领域本身有明确范式断裂，否则会被读成编年史。
- **按作者分段**（某课题组 / 另一课题组）：读者不关心谁做的，关心取舍。
- **按数据集分段**：只有在"数据条件决定结论"时才是维度，否则会把同一路线劈成两半。

## 8. 自查三问

1. 每组能不能用一句"如果只选一篇，选哪篇、为什么"回答？答不上来 → 组没选对。
2. 相关工作的段落数是否等于分组数？不等 → 有组的结论没写，或有不属于任何组的段落（R09 会报 `cited_but_ungrouped`）。
3. 每组最后一句是否指向空白？没有 → 空白与相关工作断链。
