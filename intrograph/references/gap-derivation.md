# 空白推导：让研究空白"说得实"

## 1. 一条要求

> 空白不是"这个方向还没人做"，而是**已引工作的缺口在同一维度上的交集**。

写之前先能回答：从哪一篇的哪一句局限推出？推出的是哪一类缺口？本文哪条贡献对上了？

## 2. 五种缺口类型（`limitation_kind`）

| 类型 | 定义 | 需要的证据形状 | 例 |
|---|---|---|---|
| `shared_limitation` | 多篇各自的局限指向同一件缺失的事 | ≥2 篇的 `limitation` 有共同项 | 都扫全库、都没建模语料成本 |
| `uncovered_scenario` | 方法在某场景没验证/不适用 | 该文献自己的适用范围声明 | 只在 ≥1 万标注下验证，低于此未测 |
| `conflicting_conclusions` | 两篇结论互相冲突，且冲突未被解释 | 两篇结论原文 | A 说越多越好，B 说收益早平 |
| `evaluation_gap` | 评价方式缺项（指标/划分/对照不齐） | 评价设置描述 | 都只报精度，不报预训练成本 |
| `method_gap` | 路线之间缺一环（A 的前提 B 不提供） | 两篇的方法假设 | 覆盖界需要固定空间，而下游表示正在学习 |
| `data_gap` | 数据条件缺项（规模/来源/版权/分布） | 数据集描述 | 公开库到百万级后无受控实验 |

**一张空白只写一种类型**。混写会让证据无法逐条核对。

## 3. 取证：三种 `evidence.kind`

| kind | 用法 | 脚本行为 |
|---|---|---|
| `quote` | 逐字引文，来自该文献摘要/笔记 | **会核**：NFKC + 去标点后做子串比对；找不到 → error |
| `paraphrase` | 转述，原文措辞不宜直引 | 不核数值，列入人工确认 |
| `author_judgment` | 这是你的判断，原文没说 | 不核；正文必须出现"本文认为/据我们判断/we argue" |

**取 quote 的三个要点**
1. 抄**局限句**，不要抄结论句。局限句通常在摘要最后一句，以 However / 然而 / 但 / is limited to 起头。
2. **从句子中间开始抄**最安全：从 "ignores the cost of…" 起，而不是从 "Their selection…"，避免抄错主语。
3. 抄完先自己按"忽略大小写与标点"比对一遍；脚本用的就是这条规则。

## 4. 空白的四步写法

一段之内完成，缺一步就断链：

1. **并置**：`A 优化了 <X>\[n\]，B 优化了 <Y>\[m\]，两者都不优化 <Z>。`
2. **取证**：`而 <Z> 恰恰是 <某文献原文/作者判断>。`——这里放 `derived_from` 的引文或标注。
3. **命名**：`因此空白是一处目标错配：真正决定 <可行性> 的量是 <Z>，而已引工作没有一条把它当作优化对象。`
4. **对接**：`本文把 <Z> 当作决策变量：<机制>。`——必须出现"本文/本研究/we/this paper"（R11）。

第 4 步不是客套：没有它，空白与贡献之间就没有可核对的对应关系。

## 5. 四条反面例子（都会被规则抓或被人抓）

| 写法 | 问题 | 命中 |
|---|---|---|
| "近年来该方向受到广泛关注，但仍存在许多问题。" | 空转 + 无出处 | R16 `vacuous_background` + R10 `gap_paragraph_no_citation` |
| "已有工作都没有考虑效率。" | 由未引文献推出，且"都没有"是越界断言 | R10 `gap_from_uncited_work` |
| "据我们所知，尚无工作研究此问题。" | 这是作者判断，未标注 | R02 `uncited_claim` / R11 |
| "X 的结论是错的。" | 不是缺口，是判决；且无转述依据 | 需 `paraphrase` + 人工确认 |

## 6. 空白与贡献的对应（`how_filled`）

```jsonc
"how_filled": {
  "contribution_ids": ["C1", "C2"],
  "mechanism": "先选后训：选择发生在预训练之前，语料成本变成显式预算"
}
```

- `contribution_ids` 必填且必须存在于贡献账（R10/R11）。
- `mechanism` 写"机制"不写"效果"：`先选后训` 是机制，`效果更好` 不是。
- 一条空白可以对应多条贡献；一条贡献也可以填多条空白——但**每条空白至少一条**。

## 7. 置信度（`confidence`）

| 值 | 含义 |
|---|---|
| `high` | 有 ≥2 篇 quote 级证据，且缺口类型明确 |
| `medium` | 有 quote 但只有 1 篇，或类型为 paraphrase |
| `low` | 主要靠 author_judgment；必须在正文标注，并进人工确认 |

`confidence=low` 的空白不要写成"没有任何工作…"，写成"已引工作没有…（据我们判断）"。

## 8. 自查

1. 每条空白能否一句话说出"从哪篇的哪句局限来"？不能 → 它是断言，不是空白。
2. 空白段落里有没有至少一个引用？没有 → R10。
3. 空白段落结尾有没有"本文…"？没有 → R11。
4. `derived_from` 里的文献是否都已在相关工作里被引用？没有 → R10 error（这是最常见的断链）。
5. 空白与贡献是否一一对上？对不上说明贡献写多了或空白写虚了。
