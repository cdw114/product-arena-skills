# rules.md — 引用位置、形式与去重判据细则

## 1. 引用插入位置（挂得对）

### 1.1 哪些句子需要来源
| 类型 | 例子 | 需要 |
|---|---|---|
| 具体事实 / 数字 | "ImageNet 有 128 万张图像" | 是（给出处） |
| 他人观点 / 结论 | "已有研究表明注意力可提升效果" | 是 |
| 方法 / 模型来源 | "我们采用 BERT 编码器" | 是（原始论文） |
| 比较 / 排名 | "X 优于 Y 和 Z" | 是（X、Y、Z） |
| 常识 / 定义 | "神经网络由层组成" | 通常否 |
| 本文自己的工作 / 结果 | "我们在 §3 提出…" | 否 |
| 二手引用 | "A 指出 B 认为…" | 引 A（读到的那篇），不引 B |

### 1.2 位置
- **数字顺序编码制（GB/T 7714、IEEE、Vancouver）**：标记放在**论断句句末标点之前**——`…取得了突破[1]。`，不是 `…突破了。[1]`，更不是整段末尾。
- **著者—出版年制（APA）**：括号引紧随被支撑的名词/从句——`Vaswani (2017) 提出…` 或 `…(Vaswani, 2017).`；句末括号放在句号前。
- **脚注制**：上标编号紧随论断词，脚注体放段末；与文末文献表独立。
- **一句多引**：合成一个标记。GB/T `[3,4]`（连续 `[1-3]`）；APA `(A, 2020; B, 2021)` 按字母序；多引间用分号。
- **多句一引**：若连续 ≥2 句只依赖同一文献，首句引用；若中间出现其他文献支撑的内容，后文再次引用时必须重新标注。
- **图表注**：只在图表本身转载/改编自文献时保留引用（`引自[2]` / `数据来源[3]`），不把正文论断的引用挪到图表注。
- **段落末尾引用**：若一段只有一句论断，句末 = 段末，可接受；若一段多句、只在段末一个引用 → 视为"挂整段"，`consistency.issues` 标 `citation_at_paragraph_end`，需模型/人确认到底支撑哪句。

### 1.3 锚点类型（`citation_map.json` 的 `anchor_status`）
`sentence-end` 句末标点前 · `mid-sentence` 句中（名词/从句后）· `paragraph-end` 段末且非句末 · `caption` 图表注行 · `unknown`。

## 2. 编号规则（编得顺）
- 顺序编码制：按**正文首次出现**编号；文末表顺序 = 编号顺序；图表注、附录中的引用参与编号（它们属于正文）。
- 插入：新引用在首次出现处取号，其后全部 +1。
- 删除：被删编号之后全部 −1；合并同一文献的多个引用点。
- 调序 / 合并章节：重跑即可，编号是推导量。
- 未被引用的条目：追加到表尾并列入 `uncited`（不静默删除；GB/T 允许但通常应删或补引）。
- 著者—出版年制：无编号；同作者同年用 `2020a / 2020b`，按题名字母序；文末表按第一作者姓氏字母序（中文按拼音）。

## 3. 去重判据（收得净）

### 3.1 信号与权重
| 信号 | 权重 | 判定 |
|---|---|---|
| `doi_exact` | 5.0 | 归一化 DOI 相同（去 `https://doi.org/` 前缀、大小写、尾部标点） |
| `arxiv_exact` | 4.5 | arXiv id 相同（含/不含版本号视为相同） |
| `title_exact` | 3.0 | 归一化题名相同（去标点、空白、变音符、大小写） |
| `title_translated` | 2.0 | 中英题名经模型/词典确认互为翻译 |
| `title_similar` | 1.5×r | 归一化题名相似度 ≥ 0.9（r = SequenceMatcher） |
| `authors_overlap` | 1.0×ratio | 共享姓（含拼音↔汉字桥接，减半 0.5） |
| `authors_same_first` | 1.0 | 第一作者相同 |
| `year_same` / `year_close` | 0.5 / 0.3 | 同年 / 相差 ≤1 年（预印本→正式版） |
| `venue_same` | 0.5 | 刊名/会议名相同 |
| `volume_pages_same` | 1.0 | 卷同且首页同 |

### 3.2 决策
- **score ≥ 5 → merge**；**3 ≤ score < 5 → review**（不合并，交人确认）；**< 3 → keep_separate**。
- **跨语言题名**：`title_translated` + 任一佐证信号 → merge；仅 `title_translated` → review。
- **硬阻断（任一命中即 keep_separate）**：`different_doi`（DOI 不同且题名不近似）、`title_differs`（题名都存在、非跨语言、相似度 < 0.9）、`same_author_same_year_different_title`（防同名作者误并）。
- 典型合并：预印本 ↔ 正式版（题名相同 + 作者 + 年份相近，DOI 不同但题名 exact → 不阻断）；CNKI 导出 ↔ RIS 导出（题名 exact + 卷页同）；中英文题名（翻译对 + 作者桥接）。
- 典型不合并：同作者同年的两篇不同论文；同一论文的**勘误/评论**（题名含 "Erratum" / "Comment on"）→ 题名相似度通常 < 0.9，若 ≥ 0.9 则 review。

### 3.3 合并后的规范记录
- `ref_id` = 组内最早 id（稳定、可回溯）；`merged_from` = 其余 id。
- 字段优先级：正式发表版 > 预印本 > 其他；缺字段从被并条目**补齐**（不覆盖非空）；关键词、extra 取并集。
- `merge_basis[]` 逐条记录：被并条目的 `signals, score, title, year, doi, type, source_key, source_file`。

## 4. 论断↔引用判定（对得上）
| verdict | 判据 |
|---|---|
| `supports` | 题名/摘要/关键词与论断主题明确一致，且论断不含文献未报告的具体数字 |
| `mismatch` | 文献真实但主题不符（例如引 BERT 论文支撑"卷积网络优于循环网络"） |
| `insufficient` | 库中只有题名无法判断；论断含库中未报告的具体数值；文献是综述但论断是具体实验结果 |
| `not_in_library` | 引用指向库中不存在的条目（脚本已标 `U00n`） |
`basis` 必须一句话写清"文献 X 讲了什么 / 为什么支持或不支持该句"。禁止给 `insufficient` 硬凑 `supports`。

## 5. 元数据核验
离线必查：DOI 形式 `10.NNNN/…`、年份 1500–2099、页码含数字、URL 带协议、必填字段（期刊：刊名/卷期/页；会议：会议名；书：出版社）。在线（Crossref）：题名相似度 < 0.85、刊名不同、年份不同、作者无交集 → `crossref_mismatch`。
