# failure-modes.md — 已知失败模式与处置

本 Skill 的设计来自对"基础 Agent 直接整理引用"的常见失败观察。每条给出：现象 → 本 Skill 的处置 → 残余风险。

## A. 引用位置（挂得对）
| # | 基础 Agent 常见失败 | 处置 | 残余风险 |
|---|---|---|---|
| A1 | 把引用放整段末尾，一段多句只有一个引用 | `consistency.issues` 标 `citation_at_paragraph_end`；模型 Step 4 必须逐句给 anchor | 段末单句论断仍需人确认是否只支撑末句 |
| A2 | 标记落在句号之后 `突破。[1]` | 插入时定位到句末标点前 | 稿件本身已有的错位标记**不自动移动**（不改作者原意），只记录 |
| A3 | 图表注里的引用被当作正文引用 | `anchor_status = caption`，单独统计 | — |
| A4 | 一句多引拆成多个标记 | 插入规则要求合成一个标记；重排时同一位置的相邻标记合并 | 稿件原有相邻标记不合并 |
| A5 | 给常识性陈述或本文工作加引用 | Step 4 的 §1.1 判定表 | 模型判断，需 `why` 字段可审计 |

## B. 编号（编得顺）
| # | 失败 | 处置 | 残余风险 |
|---|---|---|---|
| B1 | 插入后只改该处编号，后续不动 | 编号是推导量，整篇重算 | — |
| B2 | 正文改了，文末表序号没改 | 列表重建 | — |
| B3 | 删除引用后留下空洞 `[1][3]` | 连续性检查 `numbering_gap` | — |
| B4 | 图注/附录的 `[n]` 没同步 | 图注、附录在正文范围内，一并改写 | 脚注体内的引用不处理 |
| B5 | 数字超范围 `[9]` 但表只有 7 条 | `unresolved`，标记原样保留 | — |
| B6 | 文末表有、正文没引 | `uncited` 列出，追加表尾 | 不自动删（作者可能有意保留） |
| B7 | 同一文献多个 citekey / 中英文两条 | 去重后 `ref_id` 归一 | 复核带的对不合并 |

## C. 去重（收得净）
| # | 失败 | 处置 | 残余风险 |
|---|---|---|---|
| C1 | 中英文题名的同一篇没合并 | 翻译对 + 作者桥接（拼音↔汉字） | 无翻译对时 `review`，需人确认 |
| C2 | 预印本与正式版（DOI 不同）被当成两篇 | 题名 exact 不触发 `different_doi` 阻断；年份相差 ≤1 加分 | 题名在正式版改动较大 → review |
| C3 | 同名作者同年两篇被误并 | `same_author_same_year_different_title` 硬阻断 | — |
| C4 | 不同数据库导出字段名不同（`T2` vs `journal` vs `Source`） | 规范模型统一映射 | 未知字段进 `extra`，不丢 |
| C5 | 作者名顺序不同（Zhang Ying / Ying Zhang） | `author_keys` 同时产姓、全名、反序键 | 极常见姓（Wang/Li）桥接权重减半 |
| C6 | 合并后丢了 DOI/页码 | 字段从被并条目补齐 | — |

## D. 格式（转换与补齐）
| # | 失败 | 处置 | 残余风险 |
|---|---|---|---|
| D1 | GB/T 缺 `[J]`/`[C]` 类型标识 | 按规范类型必输出 | 未知类型 `[Z]` |
| D2 | APA 刊名没斜体、DOI 缺 | 渲染规则固定 | — |
| D3 | 中文条目用了英文作者缩写 | 按条目语言分流 | 中英混合作者列表按整体语言 |
| D4 | 卷期页丢失 | 映射表保留；缺失进 `field_report` | 不回填网络数据 |
| D5 | BibTeX 单行多字段解析丢 `{` | 已修（`_strip_braces` 单行回退） | 极不规范 BibTeX 仍可能漏字段 |

## E. 核验（对得上）
| # | 失败 | 处置 | 残余风险 |
|---|---|---|---|
| E1 | 编造条目混入列表 | 库中无匹配 → `U00n` + ⚠ + verify error，**不删除** | 库本身含编造条目时只能靠 `--online` |
| E2 | DOI 写错一位 | 离线只能查形式；在线 Crossref 比对 | 离线无法发现 |
| E3 | 元数据与 DOI 不符（题名对、年份错） | 在线比对题名/刊名/年/卷/作者 | 中文 DOI Crossref 覆盖有限 |
| E4 | 论断与所引文献不匹配 | 模型逐句判定 + `basis` | 模型判断，`insufficient` 不硬凑 |
| E5 | 具体数字引综述文献 | 判定规则：论断含文献未报告的具体数值 → `insufficient` | 需摘要；库中无摘要时多为 insufficient |

## F. 运行与环境
| # | 情形 | 处置 |
|---|---|---|
| F1 | 输入是 PDF | 若有 pdf 工具先转文本（`pdftotext` / pymupdf）；否则 failed 并说明 |
| F2 | docx 损坏 | 异常捕获 → failed（exit 2），result.json 含原因 |
| F3 | 文献库格式未知 | 内容嗅探（`@`→bib，`TY  - `→ris，`"title"`→json，`Title:`→CNKI）；仍失败→从文末表反向构建 |
| F4 | 无 `/app` 目录（本地测试） | `work` 回退到 `out/../work` |
| F5 | 网络不通 | `--online` 静默降级离线 |
| F6 | 预算耗尽 | 脚本阶段已出 partial result；模型判断缺 → `claim_citation.pending` |
| F7 | Windows 控制台编码 | 脚本 stderr 为 UTF-8；子进程用 `-X utf8` |
