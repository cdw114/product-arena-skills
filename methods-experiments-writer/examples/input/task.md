# Task

Write the **Methods and Experiments** section for a paper that predicts a scalar
property of polymer structures with a graph neural network.

Materials available:

- `materials/config.yaml` — the configuration the training entry point loads
- `materials/train.log` — a captured training log
- `materials/train.py` — the training entry point
- `materials/README.md` — the dataset and baseline note

## Requirements

1. Cover the six elements: ordered steps, experimental setup, parameters,
   datasets and splits, baselines, reproducibility and limitations.
2. Every number must be traceable to one of the files above. If a number is not
   in a file, do not write it.
3. Where two files disagree, keep both and ask the author which is authoritative.
4. Mark anything the materials cannot answer as TO-CONFIRM.

Deliver the section as markdown, with the parameter table, the fact-to-source
map, the coverage report and the author question list alongside it.
