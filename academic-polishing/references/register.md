# 文体与语域（Register）

同一段文字，投期刊、写学位论文、申请基金、回复审稿、译成英文摘要，语气和改动力度都不一样。**先判断文体，再决定改什么。** 文体不明时按最小编辑处理（只修硬错误），并记录需人工确认。

## 各文体的要点

| 文体 | 语气 | 常见问题 | 改动力度 |
|---|---|---|---|
| 期刊论文（正文） | 克制、精确、以证据为限 | 过度强调（significantly 满天飞）、口语化、冗长的名词化 | 中：修病句、去填充、统一术语；不动论证顺序 |
| 学位论文 | 可略带说明性，但避免自我评价 | "我们系统地研究了"、"具有重要的理论意义" | 中：去自我评价词，保留说明性展开 |
| 基金申请 | 有说服力但不夸大 | "必将"、"颠覆性"、"填补空白" | 中到大：收住绝对化表述，目标写成可检验的 |
| 审稿回复（response letter） | 礼貌、直接、逐条 | 辩解语气、被动攻击、模糊回应 | 中：每条回复先答"是/否/部分"，再给理由与修改位置 |
| 中文摘要 | 信息密度高，250–400 字 | 背景铺陈过长、"本文"用法不一、半角标点 | 中：压缩背景，统一"本文/本研究"，修标点 |
| 英文摘要（ Abstract / Summary） | 一段，150–300 词，无引用 | 中式英语：the … of … is、has a very important significance | 大：允许重排主谓、删冗余，但数据与限定词不动 |
| 英文全文（中译英稿） | 母语学术英语 | more and more、play an important role、in order to、put forward、research on | 中到大：见下"中译英直译腔" |
| 方法部分 | 过去时被动/主动均可，但要统一 | 时态混用、句子过长 | 小：只修语法与时态一致 |
| 结论部分 | 与引言呼应，不新增结果 | 引入新数据、超出讨论范围的推论 | 小：删越界句，记录 |

## 中文学术语气：要消除的

- 空泛评价：具有重要的理论意义、极大地推动、引起了广泛关注、得到了广泛的应用。
- 自我评价：系统地、深入地、全面地、首次（除非确是首次且有证据）。
- 套话开头：随着…的发展、众所周知、毫无疑问。
- 套话连接：综上所述、由此可见、总而言之（确有总结时保留一次即可）。
- 名词化堆叠：对…进行了…的研究、对…开展了…的分析 → 研究了…、分析了…。
- 被动滥用：被观察到、被发现、被认为 → 主动句（"Smith 等观察到"、"研究表明"）。
- 半角标点：中文句内的 `,;:!?` → `，；：！？`；句末 `.` → `。`。
- "的"堆叠：薄膜的晶粒尺寸从约 120 nm 增加到约 250 nm → 薄膜晶粒尺寸…增至…。

## 中译英直译腔：要改写的

| 中文直译 | 母语写法 |
|---|---|
| more and more | increasingly |
| play an important role in | be central to / contribute to / 具体化动词 |
| has a very important significance | is significant for / matters because … |
| in order to | to |
| put forward | proposed / introduced |
| research on X | study of X / we studied X |
| the … of … is … (长名词链) | 改为动词句或所有格 |
| the X problem | X（多数时候 "problem" 是多余的） |
| utilize / leverage | use（除非强调"利用闲置资源"） |
| due to the fact that | because |
| a total of | 删 |
| in terms of / with respect to | 直接说 |

## 英文学术语气：要消除的

- 强化副词：significantly（无统计检验时）、dramatically、greatly、very。
- 空泛开场：It is worth noting that / Notably / Importantly（信息本身够重要就不需要宣布它重要）。
- 过度对冲：It may potentially possibly suggest → may suggest。
- 动词名词化：perform an analysis of → analyze；conduct a study of → study。

## 句长与节奏

- 中文一句超过 60 字考虑拆分；英文超过 45 词考虑拆分。
- 拆分不是切开就完：后半句要有主语，代词要能回指，逻辑连接词要对。
- 不要把每句都改成同样长度；长短交错才像人写的。

## 人称

- 中文：本文 / 本研究 / 我们 三者全篇统一；"笔者"多见于人文社科。
- 英文：we 常见于多数期刊； passive 在方法部分可接受，但引言/讨论避免连续被动。
- 学位论文用"本文"或"本研究"多于"我们"；基金用"我们/本项目组"。

## 改动力度的三个档位（在 reason 里写明用了哪档）

1. **轻**：标点、语法、错别字、术语统一。
2. **中**：句式重组、去填充、翻译腔改写、被动改主动、拆长句。
3. **重**：段落内顺序调整、合并句子、删整句冗余。
默认从 1 开始，只在必要时升到 2；升到 3 必须有任务依据（如"精简到 300 字"）。
