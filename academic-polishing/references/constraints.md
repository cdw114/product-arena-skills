# 语法、标点与格式约束

这一层是"改得对"的底线。按顺序检查：先硬错误，再标点，再长句，再格式。

## 1. 中文语法硬错误

| 类型 | 例 | 改法 |
|---|---|---|
| 成分残缺 | "通过 X 方法，使 Y 提高" | 删"通过"或补主语："我们采用 X 方法，使 Y 提高" |
| 搭配不当 | "提高效率 1.5 倍" | "提高到 1.5 倍"或"提高了 50%"（倍数不乱用） |
| 主谓不一致 | "性能和数据表明" | 看谁是主语，或拆句 |
| 关联词残缺 | "不仅 A，B 也" | 补"而且/而且 B 也" |
| 语义重复 | "约 120 nm 左右" | 删"左右"或删"约" |
| "的"字堆叠 | "薄膜的晶粒的尺寸的变化" | "薄膜晶粒尺寸的变化" |
| 量词误用 | "三个样品" vs "三份样品" | 按领域惯例 |

## 2. 中文标点

- 句内 `,;:!?` → `，；：！？`（全角）。数字、英文、单位之间保持半角。
- 句末 `.` → `。`；英文缩写的 `.` 不改（et al.）。
- 并列成分用顿号 `、`，不用逗号。
- 引号：中文用"" ''（弯引号），代码/变量名可用直引号。
- 书名号《》只用于书名、期刊名、法规名。
- 括号：中文句内用全角（）；含英文/公式时用半角 ()，全篇统一。
- 数字与中文之间是否加空格，按期刊；多数中文期刊不加，英文加。
- 省略号用"……"，不用"..."；破折号用"——"。

## 3. 英文语法硬错误

| 类型 | 例 | 改法 |
|---|---|---|
| 主谓不一致 | The results shows | The results show |
| 冠词 | in the Fig. 3 | in Fig. 3 |
| 时态 | 方法用过去时，结果用过去时，既定事实用现在时 | 全篇统一 |
| 悬垂修饰 | Using X, the yield increased | Using X, we increased the yield / With X, the yield increased |
| which vs that | 限定性从句用 that（美式） | 按 style guide |
| 比较级不完整 | higher than control | higher than that of the control |
| 不可数名词复数 | informations, equipments | information, equipment |

## 4. 英文标点

- Oxford comma 按 style guide，全篇统一。
- 数字与单位之间加空格（3.2 mg），百分号前不加（15.3%），温度按期刊。
- `et al.` 后的句点保留；句末 "et al." 不重复加句点。
- 括号内外标点：括号内完整句子才在括号内加句点。
- 引号：英文双引号 "" 或直引号按 style guide；嵌套用单引号。

## 5. 长句切分

- 中文 > 60 字、英文 > 45 词 → 考虑拆。
- 拆分前找主句（谁做了什么），从句和修饰成分剥离。
- 拆分后：后半句必须有主语；代词回指明确；加连接词（因此、而、however）保持逻辑。
- 不要把一句拆成三句碎片；拆成两句通常够。
- 台账 `edit_type=long_sentence_split`，reason 写原句长度与拆分点。

## 6. 格式（不改内容）

- 标题层级、编号（1. / 1.1 / 1.1.1）全篇一致。
- 图表引用写法统一（图 3 / Fig. 3 / Figure 3）。
- 单位写法统一（nm 不写成 nM；mL 与 ml 不混用）。
- 数学符号斜体规则按期刊（变量斜体、单位正体）。
- 段落首行缩进 / 段间距按模板；这是格式，不是润色，只在任务要求时处理。

## 7. LaTeX / Markdown 特有

- 不改命令名、键名、环境名；不改 `\label{}` 内容。
- `~`（不断行空格）保留在 `Fig.~3`、`\cite{}` 前。
- Markdown 加粗/斜体标记不参与审计（审计会剥离），但改文里要保持。
- 公式内部不改；公式前后的文字可以改。

## 8. 顺序建议

1. 跑 `init` 看 `style_hints_in_source`（半角标点、长句、翻译腔模式）。
2. 先修硬错误（语法、标点）——这些不需要判断。
3. 再处理翻译腔和冗余（需要判断，逐句记台账）。
4. 最后通读检查句长节奏。
5. `verify`；看 `style_hints_remaining_in_revised`，决定哪些是有意保留的。
